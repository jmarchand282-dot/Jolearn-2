JoLearn — première version fonctionnelle
1. Décompresse le ZIP.
2. Mets tous les fichiers dans ton dépôt GitHub Pages.
3. Ajoute icon-192.png et icon-512.png (icônes provisoires à remplacer par ton logo).
4. Dans app.js, remplace WHATSAPP_NUMBER par ton numéro au format international, sans + ni espaces.
5. Le service worker sw.js doit être enregistré depuis HTTPS pour le mode hors ligne.
